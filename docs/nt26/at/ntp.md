#  NTP

**文档版本** `1.0.0`

一次阻塞对时。对上之后本地墙钟、`AT+UTC` / `AT+TIME`、`AT+NTS` 会变。需要已驻网（`AT+ISLINK=1`）。通用约定见 [convention.md](convention.md)，状态类见 [netstat.md](netstat.md)。

Lua 对照：`require("ntp")`。

## 1. 本篇差异

| 项 | 约定 |
| --- | --- |
| 阻塞 | 等到对时结束或超时才回 |
| 时区 | 使用机内当前时区（15 分钟粒度）折到本地墙钟字符串 |
| 失败 | `+CME ERROR: 101` 之后仍跟 `OK` |
| 无参查询 | `AT+NTP` / `AT+NTP?` **会立刻对一次**，服务器固定 `ntp1.aliyun.com:123`，超时 6000 ms |

## 2. 指令一览

| 指令 | 测试 | 查询 | 设置 | 作用 |
| --- | --- | --- | --- | --- |
| `AT+NTP` | `=?` | 无参=默认服务器对一次 | `<ip>,<port>,<timeout>` | 对时并回本地时间串 |

## 3. AT+NTP {#3-atntp}

### 3.1 测试

```lua
AT+NTP=?
```

```lua
+NTP: ip,port,timeout

OK
```

### 3.2 默认服务器（查询形态）

```lua
AT+NTP
```

或 `AT+NTP?`。内部使用 `ntp1.aliyun.com`、端口 123、超时 6000 ms。

**成功**

```lua
+NTP: "YYYY-MM-DD HH:MM:SS"

OK
```

具体串格式以模组回的那一行为准（带引号）。

**失败**

```lua
+CME ERROR: 101

OK
```

未驻网、DNS 失败、服务器无应答都归 101。

### 3.3 指定服务器

```lua
AT+NTP=<ip>,<port>,<timeout>
```

| 参数 | 说明 |
| --- | --- |
| `<ip>` | 主机名或点分 IPv4 |
| `<port>` | 0～65535；**0 按 123** |
| `<timeout>` | 毫秒；**0 按 6000** |

成功/失败格式与上一节相同。

### 3.4 示例

```lua
AT+ISLINK
+ISLINK: 1

OK

AT+NTP="ntp.aliyun.com",123,8000
+NTP: "2026-09-05 17:40:01"

OK

AT+NTS
+NTS: 1

OK
```

---

## 4. 错误一览

本指令失败码在实现里统一成 **101**（超时类），即使是 DNS/连接失败也报 101。不要按 102/103 猜本条。

---

## 5. 联调顺序

先 `CFUN=1` → `ISLINK=1` → `AT+NTP` → `AT+TIME` / `AT+NTS`。
