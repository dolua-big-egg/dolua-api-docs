# hex

**文档版本** `1.0.1`

纯函数十六进制编解码。字节串 / 字节表 ↔ 无分隔小写 hex 文本。没有对象、没有回调。

```lua
local hex = require("hex")
```

平台预加载模块，无需额外 `.lua` 文件。

失败一律只返回 `nil`，没有第二返回值、也不抛错（类型不对、空串、奇数长度、非法字符都是 `nil`）。

## 1. 模块定位

调试打印、串口助手对照、把二进制帧变成可复制的 hex 时用。两个函数：

1. `hex.bytes2hex(data)`：二进制 string 或 `{0x01, 0x02, ...}` → 连续小写 hex（每字节两位，无空格、无 `0x`）。
2. `hex.hex2bytes(hex_str, mode)`：hex 文本 → 字节表（`mode=1`）或二进制 string（`mode=2`）。

不负责组协议帧、不算校验。粘包拆包见 [`framekit`](framekit.md)；串口收发见 [`uart`](../peripherals/uart.md)。

---

## 2. 框架结构

```
┌─────────────────────────────────────────────────────────┐
│  Lua 脚本                                                │
│  bytes2hex / hex2bytes                                   │
└────────────────────────────┬────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────┐
│  hex 模块                                                │
│  · 当场转换，无缓存、无实例                              │
│  · 成功推 string 或 table；失败推 nil                    │
└─────────────────────────────────────────────────────────┘
```

| 路径 | 调用当场做什么 | 是否让出协程 | 谁在等 |
| --- | --- | --- | --- |
| `bytes2hex` / `hex2bytes` | CPU 上把整段转完再返回 | **否** | 当前协程（很长的串会占住调度） |

没有后台任务、没有事件队列。

---

## 3. 阻塞语义

两个函数都是同步的：返回前整段转换做完。不让出任务协程，也不像 `uart.block` 那样挂起。短串可在回调里用；很大的缓冲会占住整台 Lua 调度，不要在 UART / MQTT 回调里转数 KB 以上的数据。

---

## 4. 常量与枚举

模块表 **没有** `lua_setfield` 常量。`hex2bytes` 的 `mode` 用整数，按下表写：

| 值 | 含义 | 用在哪 |
| --- | --- | --- |
| `1` | 返回 1-based 字节表，元素 `0`～`255` | `hex.hex2bytes` 第二参 |
| `2` | 返回二进制 string | 同上 |

其它整数（含 `0`、`3`）失败，返回 `nil`。没有 `hex.TABLE` / `hex.STRING` 符号。

---

## 5. 类型约定

| 名称 | 实际类型 | 取值 |
| --- | --- | --- |
| `data` | string 或连续数组表 | 非空。表下标 `1..#t`，每项数字且整数落入 `0`～`255` |
| `hex_str` | string | 非空，长度为偶数，只含 `0-9` `a-f` `A-F` |
| `mode` | integer | 仅 `1` 或 `2` |

没有按真假解释的布尔开关。`mode` 必须是数字：布尔、`nil` 都会令 `hex2bytes` 返回 `nil`。

数字在 Lua 里能当字符串用：`bytes2hex(65)` 会把 `"65"` 两个字符编成 hex（`3635`），不是单字节 `0x41`。二进制请传 `"\x41"` 或 `{0x41}`。

---

## 6. 模块函数

全部在模块表上。没有 userdata。

---

### 6.1 `hex.bytes2hex(data)` {#6-1-bytes2hex}

把原始字节编成小写 hex 文本。

**调用模式**

```lua
hex.bytes2hex(data_string)
hex.bytes2hex(byte_table)
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `data` | string 或 table | 是 | 见下 |

| `data` | 编进去的内容 |
| --- | --- |
| string | 每个字节两位 hex。空串 → `nil` |
| 连续数组 | `{0x01, 0x02, 0xAB}`，用 `#t` 当长度，按 `1..#t` 取值。某项不是数字、或不在 `0`～`255` → `nil`。空表 → `nil` |

缺参、不是 string 也不是 table：`nil`。

成功：长度为 `#data * 2` 的小写字符串。无空格、无换行、无 `0x`。

```lua
hex.bytes2hex("ABC")                    -- "414243"
hex.bytes2hex({0x01, 0x02, 0xAB, 0xCD}) -- "0102abcd"
hex.bytes2hex("\xDE\xAD")               -- "dead"
```

表只看数组部分：带字符串键、`#t` 之后的空洞不影响；`#t` 中间有 `nil` 时长度会在空洞处截断，后面的元素不会编进去。

---

### 6.2 `hex.hex2bytes(hex_str, mode)` {#6-2-hex2bytes}

把 hex 文本还原成字节。

**调用模式**

```lua
hex.hex2bytes(hex_str, 1)
hex.hex2bytes(hex_str, 2)
```

必须两个参数。省略 `mode` 直接 `nil`，没有默认值。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `hex_str` | string | 是 | 见第 7 节 |
| `mode` | integer | 是 | `1` 表 / `2` 二进制 string |

| `mode` | 成功返回 |
| --- | --- |
| `1` | `{ b1, b2, ... }`，1-based，值为 `0`～`255` |
| `2` | 与 `bytes2hex` 互逆的二进制 string（可含 `0x00`） |

```lua
hex.hex2bytes("0102abcd", 1)  -- {1, 2, 171, 205}
hex.hex2bytes("414243", 2)    -- "ABC"
hex.hex2bytes("DEAD", 2)      -- "\xDE\xAD"（大小写均可）
```

## 7. 编解码规则

**编码（`bytes2hex`）**

- 字母固定 **小写** `0-9a-f`。
- 每字节恰好两位，`0x0A` → `"0a"`，不会省略前导零。
- 不插入空格、冒号、`0x`。

**解码（`hex2bytes`）**

- 不区分大小写。
- **长度必须为偶数**。奇数 → `nil`。
- 只接受 `0-9a-fA-F`。空格、逗号、`0x`、换行都是非法字符 → `nil`。
- 空串 → `nil`。

常见写错：

| 写法 | 结果 |
| --- | --- |
| `"01 02"` | `nil`（空格，且长度常为奇数） |
| `"0x0102"` | `nil`（`x` 非法） |
| `"010"` | `nil`（奇数长度） |
| `"0102ab"` | 合法 |
| `hex.hex2bytes("414243")` | `nil`（缺 `mode`） |

往返：`hex.hex2bytes(hex.bytes2hex(s), 2) == s`（`s` 非空且 `bytes2hex` 成功时）。

---

## 8. 错误与返回约定

两个接口都不抛业务错（参数类型不对也是 `nil`，不是 `error`）。

| 接口 | 成功 | 失败 |
| --- | --- | --- |
| `bytes2hex` | hex string | 单独 `nil` |
| `hex2bytes` `mode=1` | table | 单独 `nil` |
| `hex2bytes` `mode=2` | 二进制 string | 单独 `nil` |

失败没有错误串。需要区分「空输入」和「非法字符」时，自己先检查长度 / 字符。

---

## 9. 资源上限与生命周期

没有实例、没有槽位、没有回调。每次调用在内部申请临时缓冲，返回后由 Lua 回收。

转换长度与输入成正比（hex 文本是字节数的两倍）。没有单独的最大长度常量；过大的串会吃内存并占住调度。

## 10. 选型对照

| 需求 | 用什么 |
| --- | --- |
| 日志里打印一帧 hex | `bytes2hex` |
| 串口助手贴过来的连续 hex 还原 | `hex2bytes(..., 2)` 再 `uart.write` |
| 按字节改某一位再发出 | `hex2bytes(..., 1)` 改表，再 `bytes2hex` 或直接 `uart.write(表)` |
| 带空格的 `"01 02 AA"` | 本模块不收。先自己去掉空白再解码 |
| 流式拆包 / 校验 | [`framekit`](framekit.md)，不是 hex |

`uart.write` 已能吃二进制 string 和字节表；hex 只是给人看、或从文本还原，不是发送前的必经步骤。

## 11. 完整示例

与 [examples/nt26/module/hex/hex_api](../../../../examples/nt26/module/hex/hex_api) 一致：

```lua
local hex = require("hex")

local h1 = hex.bytes2hex("ABC")                 -- "414243"
local h2 = hex.bytes2hex({0x01, 0x02, 0xAB, 0xCD}) -- "0102abcd"

local t = hex.hex2bytes("0102abcd", 1)          -- {1, 2, 171, 205}
local s = hex.hex2bytes("414243", 2)            -- "ABC"

local raw = "\xDE\xAD\xBE\xEF"
local back = hex.hex2bytes(hex.bytes2hex(raw), 2)
-- back == raw
```
