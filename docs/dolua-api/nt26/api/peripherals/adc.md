# adc

**文档版本** `1.1.0`

同步读电压。纯函数模块：按通道采一次，返回伏特 / 毫伏 / 微伏。没有对象、没有连续采样、没有回调。

```lua
local adc = require("adc")
```

平台预加载模块，无需额外 `.lua` 文件。

## 1. 模块定位

`adc.read(id)` 对指定通道做一次转换，得到校准后的电压。

1. 通道用整数 `1`～`5`，或模块常量 `adc.VBAT` / `adc.AIO4` …。
2. 没有 `open`/`close`。每次 `read` 自己完成转换。
3. 只提供电压通道。内部温度通道 **没有** 接到 Lua。
4. 失败返回 `nil`（没有第二返回值）。非法通道号抛错。

不要在 UART / MQTT / TCP 回调里调用：转换会占住当前协程，最长约 2 秒。

AIO 脚接模拟量；VBAT 读电池侧电压（内部已按分压折算）。不要把电池直接接到 AIO 脚。

## 2. 框架结构

```
┌─────────────────────────────────────────────────────────┐
│  Lua 脚本                                                │
│  adc.read(通道) → { v, mv, uv } 或 nil                   │
└────────────────────────────┬────────────────────────────┘
                             │
┌────────────────────────────▼────────────────────────────┐
│  adc 模块                                                │
│  · 校验通道 1～5                                         │
│  · 阻塞等到转换结束，组电压表                             │
└────────────────────────────┬────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────┐
│  ADC 硬件                                                │
│  VBAT / AIO4 / AIO3 / AIO2 / AIO1                        │
│  全系统同时一路转换                                      │
└─────────────────────────────────────────────────────────┘
```

| 路径 | 调用当场做什么 | 是否让出协程 |
| --- | --- | --- |
| `read` | 使能通道、等待采样、校准、关通道 | **否** |

---

## 3. 阻塞语义

`read` **不是** `rt.delay` 那种让出。返回前当前协程停住，其它 Lua 任务和 IO 回调都要等。单次等待上限 **2000 ms**，超时则 `nil`。

全系统同时只能跑 **一路** 转换。第二路会等到第一路结束。

---

## 4. 常量与枚举

通道号就是 `read` 的第一参。`ID_MIN` / `ID_MAX` 标合法闭区间。

| 符号 | 值 | 含义 |
| --- | --- | --- |
| `adc.ID_MIN` | `1` | 最小通道号 |
| `adc.ID_MAX` | `5` | 最大通道号 |
| `adc.VBAT` | `1` | 电池电压（内部已折算） |
| `adc.AIO4` | `2` | 模拟输入 AIO4 |
| `adc.AIO3` | `3` | 模拟输入 AIO3 |
| `adc.AIO2` | `4` | 模拟输入 AIO2 |
| `adc.AIO1` | `5` | 模拟输入 AIO1 |
| `adc.ADC0` | `5` | 与 `AIO1` 相同。模组丝印/原理图上的 ADC0 接到 AIO1 |

`0` 是内部温度通道，**未导出**。传入 `0` 或 `6` 及以上：抛 `"invalid adc id, expect 1~5"`。

推荐写 `adc.VBAT`、`adc.AIO1`，不要散落魔法数字。`ADC0` 和 `AIO1` 可互换。

AIO 在绑定里按直通输入采。输入不要超过该脚的模拟量程（常见约 1.2 V 量级，以模组硬件手册为准）。量电池请用 `VBAT`。

---

## 5. 类型约定

| 名称 | 实际类型 | 取值 |
| --- | --- | --- |
| `id` | integer | `1`～`5`，或上表常量 |
| `v` | number | 伏特（浮点） |
| `mv` | integer | 毫伏，由微伏整除 1000（截断） |
| `uv` | integer | 微伏 |

`id` 走 **integer**。不要传 boolean。

## 6. 模块函数

模块表上只有 `read`。

---

### 6.1 `adc.read(id)` {#6-1-read}

同步采指定通道。成功返回表；失败 `nil`。

**调用模式**

```lua
adc.read(adc.VBAT)
```

```lua
adc.read(adc.AIO4)
```

```lua
adc.read(adc.AIO3)
```

```lua
adc.read(adc.AIO2)
```

```lua
adc.read(adc.AIO1)
```

```lua
adc.read(adc.ADC0)
```

```lua
adc.read(1)
```

```lua
adc.read(5)
```

缺参或不是 integer：抛类型错。超出 `1`～`5`：抛 `"invalid adc id, expect 1~5"`。

**返回**

- 成功：`{ v, mv, uv }`，见 [第 7 节](#7-返回表)
- 失败（忙、超时、硬件未就绪等）：`nil`

```lua
local r = adc.read(adc.VBAT)
if not r then
    log.warn("adc fail")
    return
end
log.info("vbat %.3f V  %s mV  %s uV", r.v, r.mv, r.uv)
```

---

## 7. 返回表

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `v` | number | 电压，单位伏特 |
| `mv` | integer | 毫伏 = `uv // 1000` |
| `uv` | integer | 微伏（校准后） |

`v` 由微伏除以 `1e6` 得到，适合打印。比较、阈值判断优先用 `uv` 或 `mv`，少用浮点直接比相等。

---

## 8. 错误与返回约定

| 接口 | 成功 | 失败 |
| --- | --- | --- |
| `read` | 电压表 | 硬件/锁失败：单独 `nil`；非法 `id`：**抛** |

**无错误码。** 失败没有第二返回值 `err`，超时、互斥失败、初始化失败、转换失败都是单独一个 `nil`，脚本分不清是哪一种。

**何时 `nil`（无错误码）**

- 内部互斥锁创建或获取失败
- ADC 初始化失败
- 该通道转换失败或等待超过约 2000 ms
- 脚位被占用、未接到模拟量、硬件未就绪

**抛错摘要**

| 摘要 | 可能原因 |
| --- | --- |
| `invalid adc id, expect 1~5` | `id` 不是 1～5（请用 `adc.VBAT` / `AIO1`～`AIO4` / `ADC0`） |

缺参或 `id` 不是整数：Lua 标准 `bad argument #1`。

---

## 9. 资源上限与生命周期

| 资源 | 上限 | 说明 |
| --- | --- | --- |
| 电压通道 | 5 | `1`～`5` |
| 单次等待 | 2000 ms | 超时 `nil` |
| 并发转换 | 1 路 | 第二路等待 |
| 对象 | 无 | 无 userdata |

不必 `open`，也不必持有引用。没有连续 DMA、没有阈值中断。

AIO 与同脚 GPIO 不要同时当推挽输出再去采。脚位以模组原理图的 AIO1～AIO4 / ADC0 为准。

---

## 10. 选型对照

| 需求 | 做法 |
| --- | --- |
| 读电池电压 | `adc.read(adc.VBAT)` |
| 读外部模拟量 | `adc.read(adc.AIO1)` … `AIO4`，或 `adc.ADC0`（= AIO1） |
| 芯片内部温度 | **本模块没有** |
| 连续波形 / 示波器 | **没有**；自己 `rt.delay` 再 `read` |
| 在回调里采 | **不要** |

## 11. 完整示例

仓库里目前没有单独的 adc demo。下面可直接跑：周期打印 VBAT 和 AIO1。

```lua
local rt  = require("rt")
local log = require("log")
local adc = require("adc")

local function dump(tag, id)
    local r = adc.read(id)
    if not r then
        log.warn("%s id=%s fail", tag, id)
        return
    end
    log.info("%s v=%.3f mv=%s uv=%s", tag, r.v, r.mv, r.uv)
end

dump("vbat", adc.VBAT)
dump("aio1", adc.AIO1)

while true do
    dump("vbat", adc.VBAT)
    rt.delay(1000)
end
```
