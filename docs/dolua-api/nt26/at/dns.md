#  DNS

**文档版本** `1.0.0`

查/改 DNS 服务器、同步解析、清缓存、看承载 CID。服务器写入掉电保留区，**优先于运营商下发的 PCO**。通用约定见 [convention.md](convention.md)。

Lua 对照：`require("dns")`。默认数据承载 **CID=1**（与 `AT+CGACT` 那一路相同）。

## 1. 本篇差异

| 项 | 约定 |
| --- | --- |
| 失败 | 一律 `+CME ERROR: <n>`，**没有**短 reason |
| CID | 1～15。无参查询用默认 CID **1** |
| 服务器条数 | 每 CID 最多 **4** 个 |
| 主机名 | 最长 **256** 字符 |

---

## 2. 指令一览

| 指令 | 测试 | 查询 | 设置 | 作用 |
| --- | --- | --- | --- | --- |
| `AT+DNS` | `=?` | 无参=CID1；`<cid>?` 指定 | `<cid>,"dns1"[,…]` | 读/写服务器 |
| `AT+DNSG` | `=?` | 无 | `"<host>"[,<cid>]` | 同步解析 |
| `AT+DNSC` | `=?` | 无参=清全部 | `"<host>"` 清一条 | 清缓存 |
| `AT+DNSCID` | `=?` | 无参 | 无 | 活动 CID + 各 CID 激活态 |

## 3. AT+DNS {#3-atdns}

### 3.1 测试

```lua
AT+DNS=?
```

帮助说明无参查默认 CID、`<cid>?` 查指定、设置最多四个服务器。

### 3.2 查询默认 CID

```lua
AT+DNS
```

或 `AT+DNS?`。

```lua
+DNS: 1,"8.8.8.8","8.8.4.4"

OK
```

没有已配服务器时可能只有 `+DNS: 1`。读失败 CME **152**。

### 3.3 查询指定 CID

```lua
AT+DNS=<cid>?
```

`AT+DNS=<cid>`（没有第二参）也当查询。`<cid>` 不是 1～15 → CME **105**。

### 3.4 设置

```lua
AT+DNS=<cid>,"<dns1>"[,"<dns2>"[,"<dns3>"[,"<dns4>"]]]
```

空串服务器会被跳过。四个都空 → **105**。写失败 **153**。成功按查询格式回显该 CID。

立刻作用于协议栈 DNS（掉电保留），已建立的 TCP 不会因为换 DNS 而重连。

### 3.5 示例

```lua
AT+DNS=1,"223.5.5.5","223.6.6.6"
+DNS: 1,"223.5.5.5","223.6.6.6"

OK
```

## 4. AT+DNSG {#4-atdnsg}

同步解析，阻塞到出结果或失败。

```lua
AT+DNSG="<host>"[,<cid>]
```

省略 `<cid>` 用 1。主机空或长于 256 → **105**。解析失败 **154**。

**成功**

```lua
+DNSG: "example.com","1.2.3.4"

OK
```

无查询形态。需要链路（先 `ISLINK=1`）。

---

## 5. AT+DNSC {#5-atdnsc}

```lua
AT+DNSC
```

或 `AT+DNSC?`：清**全部**缓存，成功只回 `OK`（无 `+DNSC` 行）。

```lua
AT+DNSC="example.com"
```

清这一条。空主机 **105**。清失败 **155**。

---

## 6. AT+DNSCID {#6-atdnscid}

```lua
AT+DNSCID
```

```lua
+DNSCID: <active>
+DNSCID: <cid>,<state>
…

OK
```

| 字段 | 含义 |
| --- | --- |
| 第一行 `<active>` | 当前活动 CID；读不到活动 CID 时为 0 |
| 后续 `<state>` | `0` 未激活，`1` 已激活 |

列激活表失败 CME **156**。

## 7. 错误一览

| 码 | 指令 | 可能原因 |
| --- | --- | --- |
| 105 | DNS / DNSG / DNSC | CID 越界、空服务器、空主机、超长 |
| 152 | DNS | 读服务器失败 |
| 153 | DNS | 写服务器失败 |
| 154 | DNSG | 解析失败（未驻网、无记录、超时） |
| 155 | DNSC | 清缓存失败 |
| 156 | DNSCID | 读 CID 激活表失败 |

## 8. 联调顺序

```lua
AT+ISLINK
+ISLINK: 1

OK

AT+DNS?
+DNS: 1,"…"

OK

AT+DNSG="ntp.aliyun.com"
+DNSG: "ntp.aliyun.com","…"

OK
```
