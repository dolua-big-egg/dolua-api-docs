# doLua API

按型号查阅模块 API、硬件脚位、应用 AT，以及该型号的可用资源。当前公开型号是 **NT26**（含 NT26 PRO）。

引擎、调度机制是跨型号的，见 [doLua 核心](../dolua-core/README.md)。

| 型号 | 讲什么 |
| --- | --- |
| [NT26](nt26/README.md) | 资源名额、模块 API、硬件脚位、应用 AT |

新手安装插件、第一份工程见 [开始使用](../get-started/get-started.md)。侧边栏工程结构见 [开发助手](../dolua-assisant/README.md)。
